# Phase 4 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Design System

| Property | Value |
|----------|-------|
| Tool | none |

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding |
| sm | 8px | Button/input padding, triad element gaps |
| md | 16px | Search bar margins, card padding |
| lg | 24px | Container side padding |
| xl | 32px | Hero section top/bottom padding |
| 2xl | 48px | Section spacing |
| 3xl | 64px | Page-level spacing (Hero centered) |

Exceptions: 
- 5-digit Stop ID input field should have a fixed character width (~80px).
- Hero Search Bar height: 56px (custom touch-friendly height).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (Regular) | 1.5 |
| Label | 14px | 500 (Medium) | 1.2 |
| Heading | 24px | 700 (Bold) | 1.2 |
| Display | 48px | 800 (Extra Bold) | 1.1 |

*Note: "Display" role reserved for the large Hero Time on the Stop Dashboard.*

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #f8fafc | Background, main surface |
| Secondary (30%) | #ffffff | Search cards, dashboard panels |
| Accent (10%) | #2563eb | Primary CTA, Hero Time highlighting |
| Destructive | #dc2626 | Error states |

Accent reserved for: Primary search button, Hero Time value, active search suggestion selection.
