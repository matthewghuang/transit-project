<task type="auto">
  <name>Task 2: Update delay_consumer.py to upsert trip_delays</name>
  <files>delay_consumer.py</files>
  <action>
    Update `delay_consumer.py` to upsert the latest delay into the `trip_delays` table for EVERY `trip_update` received.
    
    Logic changes:
    1. Iterate through `sorted_updates` (or just take the first one if it has a delay) to find the most representative current delay.
    2. Upsert into `trip_delays` using `trip_id` as the primary key.
    3. Ensure the `updated_at` timestamp is set to the `header_timestamp` from the GTFS-R feed.
    
    SQL for upsert:
    ```sql
    INSERT INTO trip_delays (trip_id, route_id, delay_seconds, last_stop_id, updated_at)
    VALUES ($1, $2, $3, $4, $5)
    ON CONFLICT (trip_id) DO UPDATE SET
        delay_seconds = EXCLUDED.delay_seconds,
        last_stop_id = EXCLUDED.last_stop_id,
        updated_at = EXCLUDED.updated_at;
    ```
    
    This ensures that even if a specific stop isn't the first in the feed, we have the latest known state for the entire trip.
  </action>
  <verify>
    <automated>python delay_consumer.py (run for a few cycles and verify table content in psql)</automated>
  </verify>
  <done>`trip_delays` table is populated with real-time trip data.</done>
</task>
