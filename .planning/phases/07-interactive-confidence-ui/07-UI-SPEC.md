## Interaction & Data Binding

### Confidence Slider
- **Range:** 50% to 99%
- **Intervals:** 50, 75, 90, 95, 99 (stepped)
- **Dragging State:**
    - Update `confidenceLevel` in `filterStore.ts` instantly.
    - Re-calculate `arrive_by_time` locally using `sortedBuckets`.
    - Update `Area` shading in `DelayDistributionChart` (Recharts).

### Local Estimation Logic
- **Input:** Target percentile $P$, Array of buckets $[(m_1, c_1), (m_2, c_2), \dots]$.
- **Method:** 
    1. Calculate total observations $N = \sum c_i$.
    2. Find the smallest minute $m_k$ such that $\sum_{i=1}^k c_i \ge P \cdot N$.
    3. $Delay_{est} = m_k$.
    4. $ArriveBy_{est} = ScheduledTime - Delay_{est}$.

### Shading Synchronization
- Use two `Area` components in Recharts:
    1. **Base:** All buckets, low opacity stroke, no fill.
    2. **Confidence:** Buckets where `minute <= Delay_{est}`, Accent color fill, Accent color stroke.
